Linux

  
    
    
  • Use Chrome or Chromium. Firefox has no Web Serial, so it can't install.
    • 
    
  • Chromium from the Snap Store (Ubuntu's default): it can't open the USB port
      until you allow it once. Run this in a terminal, then close and reopen Chromium:
      
    sudo snap connect chromium:raw-usb
    
      Or use Google Chrome from google.com/chrome (the .deb), which doesn't need this.
    • 
    
  • The port is listed but won't open ("Failed to open serial port"): your
      account needs access to USB serial ports. Run this, then log out and back in:
      
    sudo usermod -aG dialout $USER
