Install the e-reader firmware from this page: plug the reader into this computer with a USB cable and press Install. Needs Chrome, Edge or Opera on a computer.

  • Your settings and reading positions stay. When the installer asks whether to erase the device, leave it unticked. Books are on the SD card and are never touched.
  • No port in the list? Hold BOOT, press RST, release BOOT, then try again. On Linux, see below first.
  • Pick the right board: firmware for another board won't show anything. Updates over Wi-Fi refuse the wrong board's file.
  • Only the LilyGo T5-2.13 has been tested on hardware so far; the other three boards are untested. See the project page and its docs.

Linux

  • Use Chrome or Chromium. Firefox has no Web Serial, so it can't install.
  • Chromium from the Snap Store (Ubuntu's default): it can't open the USB port until you allow it once. Run this in a terminal, then close and reopen Chromium: 
    sudo snap connect chromium:raw-usb
    Or use Google Chrome from google.com/chrome (the .deb), which doesn't need this.
  • The port is listed but won't open ("Failed to open serial port"): your account needs access to USB serial ports. Run this, then log out and back in: 
    sudo usermod -aG dialout $USER
